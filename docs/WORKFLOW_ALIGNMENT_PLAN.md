# 사용자 흐름 보완 계획 — 통합 문서로 이관됨

현재 사용자 작업 흐름과 지원 경계는 [`PROJECT_PLAN.md`](../PROJECT_PLAN.md) §2–4, 데이터/출력 조건은 §5–9가
유일한 기준이다. 구현된 request/selection/confirmation 흐름은 [`ENGINE_CONNECTIONS.md`](ENGINE_CONNECTIONS.md)와
[`ENGINE_IMPLEMENTATION_STATUS.md`](ENGINE_IMPLEMENTATION_STATUS.md), 현재 판정은
[`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md)를 참조한다.

이전 보완 01–03의 계약과 회차별 구현 기록은 각각 `workflow_contracts.py`, 회차 보고서 및
[`DECISION_LOG.md`](DECISION_LOG.md)에 남겨 둔다. 이 파일은 완료된 설계의 축약 인덱스이며 새 단계·요구사항·PR을 추가하지 않는다.
