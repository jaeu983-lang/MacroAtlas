# 제품 아키텍처 — 통합 문서로 이관됨

현재 제품 목적·사용 흐름은 [`PROJECT_PLAN.md`](../PROJECT_PLAN.md) §1–2, 구현/목표 엔진 경계는 §4가 기준이다.
현재 코드 경로는 [`ENGINE_CONNECTIONS.md`](ENGINE_CONNECTIONS.md), 실제 구현 상태는
[`ENGINE_IMPLEMENTATION_STATUS.md`](ENGINE_IMPLEMENTATION_STATUS.md)와
[`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md)를 참조한다.

기존 제어면·자료면·증거면 설명은 §4의 Mermaid 구조도와 역할표로 통합했다. 이 파일은 이전 링크를 위한
축약 인덱스이며, 구조 설명의 별도 사본이나 새 요구사항을 두지 않는다.
