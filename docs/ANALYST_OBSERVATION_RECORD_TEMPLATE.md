# 분석가 관찰 기록 양식

이 양식은 운영자가 실제 분석가 1–2명의 동의 후 정성 관찰을 기록하는 용도다. AI·합성 사례로 채우지 않는다. 원자료 수치, 계정·기관·개인 식별정보, 자격 증명은 적지 않는다. 이 연구는 선택 사항이며 Gate 통과나 통계적 성공률을 만들지 않는다.

## 세션 정보

- 익명 참가자 ID:
- 동의 확인: 예 / 아니요 (아니요면 진행하지 않음)
- 날짜·시간대:
- 사용 환경(운영체제, Excel/호환 프로그램):
- 사용한 workbook 및 검증한 SHA-256:
- 진행자:

## 과제 기록

각 과제마다 시간을 별도로 잰다. 참가자에게 과제와 workbook만 제공하고, 정답이나 메뉴 위치를 미리 알려주지 않는다.

| 과제 | 시작·종료 시각 | 수행시간 | 결과 | 도움 요청·시점 |
|---|---|---:|---|---|
| BLS: 시리즈 제목·계절조정 여부·기간·출처를 찾고 확인되지 않은 단위/통화를 설명 | | | 완료 / 일부 / 중단 | |
| WDI: 국가·지표·연도 정렬, 결측과 0의 구분, 비교 해석 범위를 설명 | | | 완료 / 일부 / 중단 | |

## 관찰

행동 사실, 참가자의 발언, 진행자의 해석은 각각 분리해 기록한다. 구체적인 표현이 필요하면 익명화한 짧은 인용만 남긴다.

| 시각 | 과제 | 관찰한 행동 또는 익명 발언 | 관찰 사실 / 참가자 발언 / 진행자 해석 | 혼란·오류·도움 요청 |
|---|---|---|---|---|
| | | | | |

## 실제 피드백 인계

- 참가자가 실제로 제안한 수정이 있었는가: 예 / 아니요
- 기록할 익명 요약(필요할 때만):
- FeedbackStore 입력 동의 및 후속 운영자 기록 여부:
- 사례 검토나 규칙 승격은 별도 절차로 진행했는가:

피드백을 평가 사례나 제품 규칙으로 자동 승격하지 않는다. 원문 feedback은 승인된 별도 운영 절차에서만 보존한다. 이 양식의 복사본에는 원자료 값과 개인 정보를 넣지 않는다.
