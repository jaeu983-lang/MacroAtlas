## 현재 차단 지점

Iteration 28의 evidence-backed corpus는 9/36입니다. 별도 draft 27건은 assistant-simulated이며 독립 검토 전이라 승격되지 않았습니다. PR #50이 유일한 열린 PR로 draft 상태이고, 코드 병합 가능 상태와 corpus gate는 구분합니다. 먼저 사례의 기대 답·근거·후보 지원 상태·split family를 사람이 검토해야 합니다.

## 통합 PR 묶음

회차 번호는 순차 검증 checkpoint로 유지하고, 회차마다 PR을 만들지 않습니다. dependency가 맞는 아래 묶음 단위로 review PR을 냅니다.

| PR 묶음 | 범위 | 선행 조건 |
|---|---|---|
| 1 | 28–29: 사례 corpus, split audit, 검토된 feedback의 case-draft bridge | 현재 #50에서 시작. 사례 독립 검토 및 36-case gate 전에는 승격하지 않음 |
| 2 | 30–32: baseline/candidate evaluator, policy 비교, promotion/rollback record | 묶음 1 승인과 corpus freeze |
| 3 | 33–37: 공통 TimeSeries/Observation, freshness, provider/file adapter 경계 | 같은 schema·회귀 계획으로 단계 검증, source adapter는 유지 |
| 4 | 38–39: 원자료 XLSX와 비교 workbook | 묶음 3의 호환성·최신성 계약 |
| 최종 검증 | 40: 분석가 1–2명 관찰과 evidence 기록 | 28–39 gate 통과. 기존 “23회차” 계획의 실제 시나리오를 최신 workbook에 맞게 갱신 |

각 묶음 내부에서 회차별 테스트와 gate를 순서대로 실행합니다. 앞선 gate가 실패하면 뒤 단계의 변경은 완료·승격 처리하지 않습니다. 과거 보고서의 수치와 사실은 당시 증거로 보존하고, 실행 순서만 위 기준 문서에서 관리합니다.
