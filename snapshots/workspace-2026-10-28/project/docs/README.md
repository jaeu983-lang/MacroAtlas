# MacroAtlas 문서 시작점

문서는 독자에 따라 나눴습니다. 먼저 **사용자가 MacroAtlas에 무엇을 요청하고 어떤 결과를 받는지** 확인하고, 그 다음 운영 절차와 개발 구조를 봅니다. 제안·미구현 기능은 현재 동작과 구별해 표시합니다.

## 사용자

통계 요청, 출처 확인, 결과 검토와 오류 시 선택 방법은 [사용자 문서](user/README.md)에서 시작하세요.

## 운영자

설정, API 키 보관, 실행 승인, 호출 한도와 장애 대응은 [운영자 문서](operator/README.md)에서 시작하세요.

## 개발자

코드 구조, 엔진·모듈 작업 범위, 테스트와 성능 측정은 [개발자 문서](developer/README.md)에서 시작하세요. 사용자 흐름을 먼저 보고 기술 구조로 이어집니다.

## 현재 범위와 제품 기준

[제품 기획](../PROJECT_PLAN.md)은 목표와 완료 기준을 정의합니다. 기관별 공식 문서 조사, fixture 검증, live API 실행은 서로 다른 증거이며 문서가 있다는 이유만으로 구현·live 지원을 뜻하지 않습니다.
