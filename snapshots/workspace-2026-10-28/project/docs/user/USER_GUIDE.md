# MacroAtlas 사용자 안내

**대상:** 국제금융·거시경제 통계를 요청하고 결과를 읽는 분석가와 사용자
**문서 경계:** 개발환경, API 키 설정, live 호출, 테스트 절차는 [운영자 runbook](../operator/OPERATOR_RUNBOOK.md)과 [개발자 안내](../developer/DEVELOPMENT_GUIDE.md)를 보세요.

## 현재 이용 범위

MacroAtlas에는 아직 일반 사용자가 자연어로 요청을 입력하는 제품 화면이 없습니다. 현재 확인된 실기관 수집은 World Bank Indicators API의 USA/WDI/GDP 고정 경로 한 개입니다. BEA와 e-Stat은 제한된 mock 범위이며, XLSX 작성기도 아직 구현되지 않았습니다. 기관 프로필이나 API 문서가 있다는 이유만으로 해당 기관의 자료를 지금 수집할 수 있다고 보지 않습니다.

현재 상태는 [기관 카탈로그](../operator/reference/INSTITUTION_CATALOG.md), [기관별 API 조사](../operator/reference/INSTITUTION_API_AUDIT.md), [엔진과 에이전트 경계](../developer/ARCHITECTURE.md)에서 확인할 수 있습니다.

## 통계를 요청할 때 정할 정보

새 통계 흐름이 열리면 요청에 다음 정보를 넣으면 후보를 정확히 비교하기 쉽습니다.

- 찾으려는 통계와 왜 필요한지
- 포함할 경제 부문·대상·국가 또는 지역
- 원하는 기간과 연간/분기/월간 등 빈도
- stock인지 flow인지, 총액/비율인지
- 통화·가격 기준·단위
- 이름과 공식 링크만 필요한지, 실제 관측값이 필요한지
- 출처를 하나 고를지 여러 후보를 비교할지
- 시계열을 정렬·계산하거나 특정 XLSX 모양으로 받을지

“국가별 총부채”처럼 뜻이 여러 개인 요청에는 정부부채, 민간 비금융부문 부채, 전체 경제 부채, 외채 등 후보가 있을 수 있습니다. “국가별 비중”도 데이터 분포 비중인지 포트폴리오 위험 가중치인지에 따라 계산이 달라집니다. 시스템이 근거 없이 하나를 정해서 계산해서는 안 됩니다.

## 후보·수집·출처의 차이

후보의 이름이나 링크를 찾는 일은 관측값을 수집하는 일과 다릅니다. 결과를 비교할 때 기관, 실제 통계 작성기관, API 제공자, dataset/series 식별자를 구분합니다. 공식 API 문서, MacroAtlas adapter, mock/fixture 검증, 실기관 응답은 별도 단계이며, 하나를 통과했다고 다른 단계도 된 것은 아닙니다.

향후 XLSX 결과 기능이 구현되면 Definitions에서 지표의 원 정의·단위·빈도·국가·기간·출처·개정 범위가 Data에 어떻게 연결되는지 확인하세요. raw 원응답과 실행 이력은 표시용 workbook과 별도로 보존합니다.

## 기간이 맞지 않는 자료

두 series가 월별이라는 사실만으로 둘 다 월말 stock이라고 볼 수 없습니다. 월평균·월중 유량·월말 stock·분기말 stock은 통계적 의미가 다릅니다. 정렬을 제안하기 전에 공식 방법론과 관측 시점 의미를 확인해야 합니다.

향후 방법론·비교가능성 엔진(작업명)은 정렬 가능/불가/미확인을 판정하고, 별도의 변환 엔진은 사용자 승인 정책만 실행하는 구조로 기획돼 있습니다. 정렬할 수 없으면 그 이유를 표시하고 원 주기 유지, 별도 시트/파일, 계산 보류 중 대안을 제안해야 합니다. 현재 이 엔진이나 XLSX 기능이 구현된 것은 아닙니다.
