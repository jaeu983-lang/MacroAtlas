# MacroAtlas 사람용 대화 테스트 예시

**목적:** 사람이 에이전트에게 아래 문장을 실제로 입력하고, 질문과 답변이 자연스럽고 안전하게 이어지는지 확인한다.

> **현재 상태를 먼저 확인하세요.** 이 파일은 사람이 재생할 대화 테스트 시나리오이자 기대 대화 예시다. 현재 MacroAtlas 저장소에는 자연어 대화 UI/LLM이 없고 `WorkflowService`는 질문 필드와 선택지를 구조화된 데이터로 반환한다. 따라서 아래 문장은 현재 프로그램이 자동 생성한 transcript가 아니다. 현재 연결된 에이전트에서 실제로 대화를 실행한 뒤 `실제 응답` 칸에 기록해 비교한다. fixture/mock 응답과 실제 기관 응답도 구분한다.

## 실행 방법

1. 한 예시씩 새 대화에서 시작한다. 예시 사이의 정보나 이전 답변을 재사용하지 않는다.
2. `사용자 입력`을 순서대로 보내고, 중간 응답을 읽은 다음 해당 `사용자 답변`을 입력한다.
3. 에이전트가 다른 말을 해도 실제 응답을 그대로 기록한다. 기대 응답을 복사해 에이전트에게 알려주지 않는다.
4. “수집 완료”라고 말하면 실행 이력, 기관, dataset/series ID, 출처 URL, live/fixture 여부 및 생성 파일을 확인한다.
5. 해당 기능이 없거나 live 실행이 꺼져 있으면 미지원/미실행으로 기록한다. 모의 응답을 실제 출처 수집으로 인정하지 않는다.

각 예시의 통과 조건은 **기대 동작**이다. 문장의 세부 표현은 바뀌어도 되지만 데이터 의미·동의·출처 정책은 바뀌면 안 된다.

## 1. 조건이 빠진 기본 요청 — 필요한 항목만 묻기

**사용자 답변 1**

> 명목 GDP, 2015년부터 2024년까지. 연간이면 돼.

**MacroAtlas 기대 응답 2**

> 조건을 정리했습니다: 미국, 명목 GDP, 연간, 2015–2024. 선택 후보는 World Bank WDI의 `NY.GDP.MKTP.CD`입니다. 이 경로는 출처 단위/빈도를 응답에서 확인할 수 없는 경우 그 값을 미상으로 보존합니다. 결과 형식은 raw JSON입니다. 이 후보로 진행할까요?

**사용자 답변 2**

> 응. 진행해.

**MacroAtlas 기대 응답 3**

- 네트워크가 꺼져 있으면 live 수집이 된 것처럼 말하지 않는다.

## 2. 명목·실질 후보가 함께 나오는 경우 — 임의 선택 금지

**사용자 답변 1**

**MacroAtlas 기대 응답 2**

> 알겠습니다. 후보 정의와 기준년/가격 방식이 공식 메타데이터에서 확인되는지 먼저 비교하겠습니다. 현재 지원되지 않는 실질 GDP 어댑터만 있거나 기준 가격을 확인할 수 없으면 명목 GDP로 대체하지 않고 그 한계를 알려드리겠습니다.

**사용자 답변 2**

- 필수 정의가 불명확하면 미확인/검토 필요 상태를 유지한다.

## 5. 일본·중국 메타데이터 — 영어 우선, 원문 보완

**사용자 입력 1**

**사용자 답변 1**

> 소비자물가지수. 월별로 2020년 이후.

**MacroAtlas 기대 응답 2 — 영어 메타데이터가 있는 경우**

**대체 실행 — 영어의 특정 정의 필드가 실제로 없을 때만**

> 이 후보의 영어 응답에는 분류 정의가 없습니다. e-Stat의 일본어 원문 정의를 보완 조회해 원문과 언어를 함께 보존하고, 영어 기준 메타데이터로 정규화한 뒤 한국어로 설명하겠습니다. 관측값이나 코드의 의미를 번역으로 바꾸지는 않겠습니다.

**사용자 답변 2**

> 좋아. 둘 다 원문을 보존해.

**통과 조건**

- 일본어/중국어 fallback은 실제 영어 metadata 부재에만 적용한다. 429, timeout, 빈 관측치를 언어 부재로 취급하지 않는다.

- 시리즈 ID·코드·관측값·단위 숫자는 바꾸지 않는다.

## 6. 결측치와 0 — 서로 다른 값 유지

**사용자 입력 1**

> 세 기간의 금융 데이터를 받았는데 한 기간은 0이고 다음 기간은 비어 있어. 합계 계산해줘.

**MacroAtlas 기대 응답 1**

> 0은 보고된 값이고 빈 값은 결측일 수 있어 둘을 합치기 전에 원자료의 상태 코드와 정의를 확인해야 합니다. 어느 기관·dataset·series인지와 원본 파일 또는 조회 결과를 알려주세요.

**사용자 답변 1**

> 원본에는 2022년 0, 2023년 null이라고 돼 있어.

**MacroAtlas 기대 응답 2**

> 원본 표시를 유지하겠습니다. 2022년은 보고된 0, 2023년은 결측으로 별도 저장하고, 출처가 결측의 이유를 설명하지 않으면 원인을 추정하지 않겠습니다. 결측을 0으로 바꾼 합계는 만들지 않겠습니다. 원자료 기준 요약과 결측을 제외한 요약이 필요하면 각각 구분해서 보여드릴게요.

**통과 조건**

- `0`, `null`, suppressed, unavailable을 한 값으로 합치지 않는다.
- 결측을 임의로 0으로 대체하지 않는다.
- 출처에 없는 결측 원인을 만들어내지 않는다.

**실제 응답:**
**판정:** ☐ 통과 ☐ 실패 ☐ 미지원

## 7. 429/일시 오류 — 안전 중단과 재개

**사용자 입력 1**

> 무작위로 고른 다른 dataset들도 가져와서 테스트해줘.

**MacroAtlas 기대 응답 1**

> 먼저 API 문서와 기관별 요청 한도를 확인한 뒤, 유효한 dataset/series에서 seed가 기록되는 표본을 고르겠습니다. 각 표본은 저장 후 read-back까지 검사합니다. 아직 API 어댑터가 없거나 호출 예산이 확인되지 않은 기관은 live 테스트를 건너뛰고 미실행으로 표시하겠습니다. 수 시간 soak 전에 짧은 안전 테스트 결과와 호출 상한을 보여드리겠습니다.

**테스트 중 예상 응답 — mock에서 429 주입**

> API가 429를 반환했습니다. 기관별 backoff 정책에 따라 해당 작업을 대기/중지 상태로 기록했습니다. 다른 기관으로 실패를 숨기거나 같은 페이지를 중복 저장하지 않습니다. 재시도 가능 시각과 재개할 표본 ID를 보존했습니다.

**사용자 답변 1**

> 재개해.

**MacroAtlas 기대 응답 2**

> 재시도 시각이 도달했고 재개 조건이 그대로인지 확인하겠습니다. 앞서 완료한 표본은 재사용 가능성을 검증하고, 실패한 표본부터 이어갑니다. 실제 API가 계속 429를 반환하면 기관별 중지 기준에서 멈추겠습니다.

**통과 조건**

- 임의 endpoint/query를 live로 보내지 않는다.
- 동일 seed·표본·진행 상태를 기록하고 실패 후 재개할 수 있다.
- 429를 성공이나 데이터 없음으로 보고하지 않는다.
- 다른 기관의 결과와 섞어 성공률을 계산하지 않는다.

**실제 응답:**
**판정:** ☐ 통과 ☐ 실패 ☐ 미지원

## 8. 무작위 표본과 장시간 실행 — 기관 한도 밖으로 나가지 않기

**사용자 입력 1**

> 4시간 동안 GDP 말고도 서로 다른 dataset을 랜덤으로 골라서 실제 API로 수집하고, 넣었다가 다시 읽어 오류가 있는지 확인해.

**MacroAtlas 기대 응답 1**

> 먼저 공식 API 문서, 구현된 어댑터, 인증 준비, 기관별 호출 한도를 확인하겠습니다. 무작위로 고르는 대상은 공식 catalog에서 확인된 유효 dataset/series로 제한하고, 같은 계열의 인접 series에만 치우치지 않도록 표본 다양성을 기록하겠습니다. 각 표본은 원본과 hash를 보존하고 저장 후 read-back 합니다. 현재 live 지원이 확인되지 않은 기관은 실행 대상에서 제외하고 이유를 표시하겠습니다.

**사용자 답변 1**

> 못 도는 기관이 있으면 표시하고, 가능한 데만 해.

**MacroAtlas 기대 응답 2**

> 준비된 기관과 미지원/미확인 기관을 분리해 실행 계획을 보여드리겠습니다. 각 live 표본에는 seed, 기관/dataset/series ID, 요청 횟수·bytes·시간 예산과 중지 기준이 필요합니다. 공식 호출 제한을 확인하지 못한 기관에는 live 요청을 보내지 않겠습니다. 확인 가능한 표본의 짧은 canary를 먼저 끝낸 뒤 4시간 soak를 시작하겠습니다.

**실행 중 예상 응답**

> 현재 sample은 저장/read-back 검증을 통과했습니다. 원본 hash, 행 수, 결측/0 상태가 일치합니다. 아직 실행하지 않은 기관/표본과 제외 사유는 별도 목록에 남아 있습니다.

**통과 조건**

- 선택된 dataset/series가 실제 공식 API catalog에서 나온 유효 ID다.
- seed와 sample 모집단이 재현 가능하고, 인접 dataset만 반복 선택하지 않는다.
- 미구현/미확인 기관을 성공으로 계산하지 않는다.
- 요청 한도/예산이 미확정인 기관에는 live 호출을 보내지 않는다.
- local read-back, revision 변화, missing/zero, raw hash를 구분해 보고한다.
