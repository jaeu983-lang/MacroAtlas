# 08회차 보완 — 개념군 검색과 통계 유형 선택

기준일: 2026-10-25. 사용자가 제시한 “미국 GDP는 명목·실질 GDP를 모두 후보로 제공” 요구를 반영한다.

상태: 08회차 보완 구현·fixture 검증 완료. 전체 pytest 515개와 Ruff 통과.
구현 결과·변경 파일·한계는 docs/developer/history/CONCEPT_SEARCH_REVISION_REPORT.md 참조.

## 현재 구조와 결함

- 자연어 일부를 DataRequest.concept로 해석하고, MetadataRecord.concept_id와 문자열이 다르면 즉시 후보를 제외한다.
- VariantAttributes에는 가격 기준·조정·측정 방식이 있지만 Concept ID 필터 이후에만 검사한다. 따라서 서로 다른 하위 ID를 가진 명목·실질 GDP가 넓은 GDP 질의에서 누락된다.
- 그룹도 Concept ID와 정의 문구의 동일성을 요구한다. 서로 다른 가격 기준 때문에 정의가 다른 정상 GDP 변형을 함께 제시하기 어렵다.
- 기존 499개 테스트 통과는 이 검색 재현율 문제를 검증한 증거가 아니다. 이 문서는 08회차의 보완이며 09회차 시작이 아니다.

## 제품 정책

- 사용자 질의의 의미가 넓으면 그 개념군에 속한다는 근거가 있는 하위 유형을 주요 후보로 포함한다. 검색 포함은 통계적 등가성·상호 대체·자동 수집 승인을 뜻하지 않는다.
- “미국 GDP”: 명목 GDP와 실질 GDP를 모두 주요 후보로 제시한다. 통화·가격 기준·기준년·조정·주기·단위·가용 범위·수집 지원 여부를 각각 보존한다. 한 유형만 발견했으면 그 조회 범위를 표시하고 전체 유형을 조사했다고 주장하지 않는다.
- “미국 명목 GDP”: 명목 유형만 주요 후보로 제시한다. 실질 GDP를 자동 대체하지 않는다. 명목 여부 미상/메타데이터 충돌은 검토 대상으로 남긴다.
- GDP 증가율·1인당 GDP는 수준 GDP와 구별되는 관련 지표다. 관련 참고 후보로 표시할 수 있으나 요청한 수준 GDP의 정확 대체나 자동 수집 대상으로 삼지 않는다. GNI·국가부채 등 근거 없는 개념은 GDP 주요 후보에 포함하지 않는다.
- ID가 같아도 가격 기준·수준/변화율 등 출처 메타데이터가 충돌하면 정확 일치로 판단하지 않는다. 이름이 비슷하다는 이유만으로 상하위/동의 관계를 만들지 않는다.
- 검색 단계는 후보와 차이를 먼저 보여준다. 사용자가 가격 기준이나 후보를 지정하지 않았다면 수집 전에 필요한 선택을 묻는다. 명목·실질을 임의 기본값으로 정하거나 모두 자동 수집하지 않는다.
- 비교/전부 보기에서는 선택 질문 때문에 검색 결과를 숨기지 않는다. 제공된 메타데이터에서 발견한 유형과 미발견/미지원 범위를 구분하고, 가격 기준이나 수준 여부가 미상이면 확정 매칭으로 표시하지 않는다.

## 최소 설계

1. mapping에 제한된 버전형 검색 관계 정책을 둔다. 검색용 개념군 ID와 출처의 series ID/원래 concept_id를 구분하고 원래 식별자를 덮어쓰지 않는다.
2. 관계는 근거 참조가 있는 subtype 또는 related로 명시한다. 초기 GDP 개념군과 명목/실질 포함 규칙은 이번 제품 요구에 따른 검색 정책이며, 기관 원통계의 공식 등가성/라이선스 사실로 승격하지 않는다.
3. 후보마다 relation, family_id, 원래 concept_id, 관계 경로/정책 근거, 가격 기준 등의 차이와 포함·제외 사유를 반환한다. related는 실행 가능한 주요 제안과 분리한다.
4. 그룹은 동일한 정의 문구 대신 검증된 개념군 포함 근거를 사용한다. 범위·stock/flow·수준/변화율이 다른 후보를 같은 변형 그룹으로 합치지 않는다. 명목·실질은 같은 GDP 검색 그룹에 서로 다른 유형으로 표시한다.
5. 기존 조건·출처 버전·가용성 검사를 유지하고, 검색 정책 버전도 확인 스냅샷에 묶는다. 정책/메타데이터 변경 시 재검색·재확인한다.
6. 자동 온톨로지 생성, 무제한 관계 탐색, 임의 유사어 추론은 추가하지 않는다. 관계 수·탐색 깊이에 상한을 두며 충돌/순환은 오류로 처리한다. 원통계의 범위 관계와 검색용 개념군 관계는 별개다.
7. 초기 내부 가격 기준은 nominal/real을 사용한다. 원문 코드의 정규화 근거는 기존 메타데이터 어댑터에서 보존하며 관계 정책으로 누락된 source 속성을 채우지 않는다. 요청을 명목→실질 또는 구체 유형→넓은 GDP로 바꾸면 이전에 암묵 적용된 가격 조건과 선택을 유지하지 않는다.

## 수용 기준

| 질의/조건 | 주요 후보 | 확인 및 금지 사항 |
|---|---|---|
| 미국 GDP, 명목/실질이 서로 다른 ID | 명목·실질 모두 | 가격 기준/후보 선택 전 자동 수집 금지 |
| 미국 GDP, 같은 ID에 다른 가격 기준 | 명목·실질 모두 | 유형 차이 보존, 명목 기본값 없음 |
| 미국 명목 GDP | 명목 | 실질 대체 금지, 미상은 검토 |
| GDP 증가율·1인당 GDP 자료도 존재 | 수준 GDP와 구별된 관련 참고 | GDP 수준의 정확 일치로 표시하지 않음 |
| Concept ID는 같지만 measure=change/rate | 관련 지표 또는 검토 | ID 동일만으로 수준 GDP로 확정하지 않음 |
| GDP라는 이름의 GNI/부채/관계 미상 ID | 주요 후보에서 제외 | 이름만으로 관계 생성 금지 |
| 하위 유형 ID와 가격 기준이 상충 | 검토 대상 | 상충 사실을 숨겨 정확 매칭하지 않음 |
| 사용자가 후보/가격 기준을 명시 | 선택한 유형만 확인·연결 | 이미 정한 조건 재질문 없음 |
| 관계 정책 또는 원문 개정 | 기존 실행 차단 | 새 확인 기록 필요 |
